# Каталог до сокращения и тестовый режим ДДС

В `catalog.md` — полный список 75 уникальных названий и подробности сценариев: 73 билета (включая архивные и пользовательские) и 2 служебных снимка занятий, также сохранённые для полноты. Снимки имеют описание «Снимок занятия» и не являются самостоятельными билетами каталога. В `catalog.json` — полные данные выбранной версии каждого билета для повторного использования. Выгрузка сделана до сокращения из основной базы и 61 локального демонстрационного профиля; правила выбора версии и все источники указаны внутри экспорта. История попыток и учётные записи не экспортировались. Это архив учебного материала, не резервная копия баз.

В обычном запуске исходной программы теперь выбран временный режим `TRAINING_CATALOG=two-dds` (значение по умолчанию). Доступны:

1. **ДДС · взаимодействие с бригадой** — принять карточку, связаться с бригадой, зарегистрировать доклады, статусы и комментарии.
2. **ДДС: карточка вне зоны обслуживания** — обоснованно не принять карточку и указать передачу по принадлежности.

Новые базы получают только эти два билета. В существующих базах остальные записи и результаты остаются на месте, но скрываются из каталога, списка назначений, вводных уроков и подбора новых занятий. Старые билеты нельзя запускать по прямому адресу в этом режиме. Голосовые модели и лаборатория `ai_lab` не менялись.

Для возврата полного режима задайте переменную окружения `TRAINING_CATALOG=full` перед запуском. В запуске через `run.py` её также можно указать в локальном `.env`. Полный режим включает прежнее заполнение встроенных каталогов; уникальные пользовательские билеты из архива автоматически не импортируются.

Изменения относятся к исходному коду. Уже собранный EXE содержит старый код до следующей сборки. Архив размещён в `content`, потому что `docs` исключён из Git; его можно включить в ваш следующий push. Агент коммит и push не выполнял.

Проверки из корня проекта:

```powershell
.venv\Scripts\python.exe scripts\check_two_dds_catalog.py
.venv\Scripts\python.exe -m pytest apps/api/tests/test_two_dds_catalog.py -q
```

Проверка использует отдельную временную базу и тестовые WAV-файлы вместо реальной нейросетевой озвучки. Обычные регрессионные тесты запускаются с полным каталогом, чтобы продолжать проверять режим 112 и исторические сценарии; специальный тест отдельно проверяет новый режим по умолчанию.
