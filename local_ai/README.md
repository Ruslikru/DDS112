# Локальная модель

По умолчанию используется Qwen3 4B Instruct 2507 Q4_K_M (2 497 281 120 байт). В настройках можно выбрать более быструю Qwen3 0.6B Q4_K_M (396 705 472 байт). Источники, ревизии и SHA-256 указаны в manifest.json. Лицензия Apache-2.0.

На сервере доступны CPU и GPU Vulkan, по умолчанию CPU, 6 потоков и контекст 4096 токенов. При переходе с прежней модели настройки вычислений переводятся на CPU; GPU можно выбрать заново. Облачных запросов нет. Веса не дообучаются: подтверждённые преподавателем формулировки передаются как дополнительные примеры для того же задания и критерия. Примеры можно отозвать.

Администратор выбирает сервер или разрешённые ПК класса. Для вычисления на ПК нужно запущенное Windows-приложение, допуск рабочего места и отдельное разрешение в настройках ИИ. Каждый узел обрабатывает один запрос одновременно. Если узлы заняты, отключены или дали ошибку, используется сервер. Телефон обращается к серверу через браузер и не запускает модель самостоятельно.

Файлы: models/Qwen3-4B-Instruct-2507-Q4_K_M.gguf, models/Qwen3-0.6B-Q4_K_M.gguf, runtime/cpu/llama-server.exe, runtime/vulkan/llama-server.exe и сопутствующие DLL. Параметры изменяются в разделе «Система». Предварительная оценка допускает ошибки: итог подтверждает преподаватель.

Мастер билетов генерирует краткую историю по заданным признакам. Учебный адрес и имя выбираются программой; критерии строятся из тех же фактов. Автор проверяет и публикует черновик отдельно.
