# Локальные модели

Приложение использует три семейства моделей без облачных запросов:

- **Qwen3 4B Instruct 2507, Q4_K_M** — общий экземпляр для ассистента, создания билетов и минивопросов, анализа выполненных билетов и разговоров.
- **GigaAM v3** — распознавание речи преподавателя и ученика.
- **Piper** — озвучка голосами Денис, Ирина и Руслан (29800).

Простые команды ассистента обрабатываются правилами без обращения к Qwen. Для текстовых задач используется один процесс llama.cpp; отдельные копии для ассистента и телефонных разговоров не запускаются. Маленькая Qwen и её адаптер в сборку не входят.

При старте сервера фоном выполняются пробный запрос Qwen, распознавание с декодированием и синтез каждого голоса Piper. В нижней полосе зелёный индикатор означает завершённый прогрев, синий — прогрев, красный — отсутствие готовности. Прогрев убирает первоначальную загрузку, но обработка каждого нового запроса всё равно занимает время. Распознавание ассистента использует тот же серверный движок, что и телефон.

По умолчанию Qwen получает 6 потоков, GigaAM и Piper — по 2. Число потоков меняется администратором в настройках звука. Qwen поддерживает CPU и GPU Vulkan; GigaAM — CPU и CUDA; Piper работает на CPU. Сведения об источнике и SHA-256 текстовой модели находятся в `manifest.json`.

Старые настройки маленьких текстовых моделей переводятся на Qwen 4B. Настройки голосов и устройств сохраняются. Итоговую оценку подтверждает преподаватель.
