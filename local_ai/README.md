# Локальные модели

Приложение использует фиксированный состав моделей без облачных запросов:

- Генерация карточек: Qwen3 4B Instruct 2507, Q4_K_M.
- Ассистент преподавателя и анализ звонков: Qwen 2.5 1.5B Instruct, Q4_K_M, вместе с адаптером предметного обучения после 1000 шагов.
- Озвучка: Piper, голоса Денис, Ирина и Руслан (29800).
- Распознавание микрофона: GigaAM v3.

Файлы базы и адаптера Qwen 2.5 нужны одновременно: `models/Qwen2.5-1.5B-Instruct-Q4_K_M.gguf` и `models/qwen-dds-1000-f32.gguf`. Адаптер подключается llama.cpp через `--lora`. При его отсутствии программа сообщает об отсутствии модели; необученная база вместо неё не запускается.

Источники и SHA-256 находятся в `manifest.json`. Сборка переносит только перечисленные модели. Скрипт `scripts/prepare_application_models.py` копирует проверенную базу и адаптер из лаборатории, сверяя контрольные суммы; исходные эксперименты не изменяются.

Старые настройки Whisper, Silero, Qwen TTS и прежних маленьких Qwen при чтении переводятся на текущие модели. Piper сохраняет выбранный голос. Автоматического дообучения нет; итоговую оценку подтверждает преподаватель.

CPU и GPU Vulkan доступны для текстовых моделей; GigaAM поддерживает CPU и CUDA, Piper работает на CPU. По умолчанию 6 потоков и контекст 4096 токенов. Администратор выбирает сервер или разрешённые ПК класса; при отсутствии свободного узла запрос карточки выполняет сервер.
