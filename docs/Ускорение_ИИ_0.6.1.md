# Ускорение проверки комментариев — 0.6.1

По журналу пользовательская попытка №5 проверялась 23,264 секунды: обработка входа 10,898 с, генерация ответа 12,254 с. Режим CPU, 6 потоков, та же Qwen3-4B Q4_K_M. Видеокарта и внешние API для ускорения не используются.

## Изменения

- Убраны пустые поля карточки и повторная передача служебной истории с теми же комментариями. Текст ученика, эталон, непустые сведения карточки и полученные сообщения сохранены.
- Объяснение ограничено одним предложением до 160 символов, цитата — 70 символами. Полноценная смысловая оценка сохраняется; модель не заменена поиском ключевых слов.
- Фоновая очередь проверяется каждые 0,5 с вместо 2 с. Открытый результат во время анализа обновляется раз в секунду вместо 2,5 с.
- В журнале запроса отдельно записываются время запуска модели и время inference.

## Замеры на текущем ПК

Вход для комментария со скриншота сократился с 1078 до 569 токенов, выход — со 170 до 69.

| Проверка | После изменения | Оценка |
| --- | ---: | --- |
| Комментарий со скриншота | 9,662 с | Частично |
| Полное описание действий и результата | 6,494 с | Полностью |
| Просьба поставить максимальный балл вместо ответа | 5,949 с | Неверно |

Эти три замера сделаны с загруженной моделью в CPU-режиме. Это длительность запроса модели, без ожидания очереди и обновления экрана. Холодный запуск и конкурирующая нагрузка увеличивают время. Гарантия ответа за фиксированное число секунд не заявляется.

При сравнении старый обработчик принял последнюю проверку за частичный ответ: контекст ещё содержал комментарии из исходной попытки. В новом запросе этот дублирующий источник исключён, и модель оценила собственно текст ученика как неверный.

21 автоматический тест и сборка интерфейса прошли. Проверены сохранение полученных фактов при сжатии контекста, частичные баллы, ошибочная цитата, повторная проверка и приоритет преподавателя. Собранный EXE 0.6.1 прошёл проверку WebView2, локальной модели, перезапуска с сохранением данных и резервного копирования. Минимальное оборудование ТЗ и многопользовательская нагрузка отдельно не проверялись.

Сырые результаты локального сравнения: `tmp/ai-061/benchmark.json`. Существующие оценки учеников автоматически заново не пересчитываются.
