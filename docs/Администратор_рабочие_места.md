# Управление учебным контуром

Администратору доступны семь вкладок: рабочие места, настройки, билеты,
пользователи, минивопросы, службы, обновление системы.

## Рабочие места

Список показывает запущенные устройства, включая сервер и экземпляры без входа
в учётную запись. CPU, оперативная память, диск, связь, версия и состояние ИИ
обновляются каждые две секунды. Совместимые GPU определяются через Vulkan.
Для NVIDIA дополнительно показываются загрузка, видеопамять и температура,
если драйвер предоставляет nvidia-smi. Отсутствующий показатель не заменяется нулём.

Кнопки под устройством: удалённый рабочий стол, выход из учётной записи,
закрытие тренажёра, исключение из учебного контура. Последнее отзывает секрет
устройства и закрывает приложение; файлы и Windows не удаляются. Сервер
нельзя исключить из собственного контура. Команды разрешены только администратору.

В демонстрации на одном ПК просмотр и ввод относятся только к окну выбранного
тренажёра. При сетевом запуске показывается рабочий стол Windows; ввод не
обходит защищённый экран Windows/UAC. Сеанс удалённого просмотра прекращается,
если администратор закрыл окно либо не обновляет его 15 секунд.

## ИИ и резервные копии

Для каждого доступного устройства можно выбрать CPU или обнаруженную GPU;
рабочее место также может использовать ИИ учебного сервера. Отсутствующая GPU
недоступна для выбора. Локальные вычислители используются сервером как пул
обработки запросов; при недоступности выбранных вычислителей действует
существующий механизм возврата к серверу. Настройки подтверждает само устройство.

Резервное копирование включено по умолчанию каждые 24 часа при работающем сервере.
Создаётся согласованный снимок SQLite, копия media и настроек с SHA-256-манифестом.
Путь может быть локальным абсолютным путём сервера или UNC-папкой, доступной
его учётной записи Windows. Пароль сетевого хранилища в приложении не хранится.
Для восстановления остановите тренажёр, сохраните текущие данные отдельно,
восстановите database.sqlite как dispetcher.db и media в папку профиля.

## Службы

Теги описывают службу; вопросы отображаются при открытии службы в карточке.
Автоматическое добавление срабатывает при выполнении всех заданных условий
по типу, признакам, пострадавшим, описанию, объекту или округу. Без условий
служба автоматически не выбирается. Фактическое оповещение остаётся действием
оператора при сохранении карточки.

## Обновления

При необходимости пакет готовится отдельной командой:

```powershell
.venv/Scripts/python.exe scripts/create_update.py release/Dispetcher112-0.8.0-admin tmp/update.zip --version 0.8.0
```

Версия манифеста должна совпадать с VERSION в сборке. Пакет содержит EXE,
_internal и update.json со списком SHA-256; модель ИИ переносится из текущей
установки. Загрузка пакета сама по себе ничего не обновляет. Администратор
выбирает рабочие места и отправляет обновление; сервер обновляется отдельно
после их завершения. Нужен свободный диск под новую копию приложения и модели.

Пакет проверяется на состав, контрольные суммы и безопасные пути; устанавливается
рядом с прежней версией в папке данных профиля. После перезапуска новая версия
подтверждает выполнение. Обычный запуск прежнего EXE затем перенаправляется к
подтверждённой версии профиля. Без подтверждения за 10 минут показывается ошибка.
Прежняя сборка и данные сохраняются. Используйте пакеты из доверенного источника:
SHA-256 проверяет целостность, но не является подписью издателя.

Сетевой перенос обновлений, защищённый рабочий стол Windows и доступ к UNC
требуют отдельной проверки на целевых компьютерах.


## Просмотр экранов — 28 сентября

Рабочие места показаны сеткой по три карточки. Нажатие на трансляцию
разворачивает карточку на ширину списка; стрелки переключают экраны, крестик
возвращает сетку. Этот просмотр не отправляет клики и клавиатуру. Для управления
нужна отдельная кнопка подключения. Подключение к текущему ПК запрещено.

В демонстрации захват окна использует WebView2 CapturePreviewAsync без изменения
размера окна Chromium. Удалённый экран масштабируется при изменении размера
диалога с сохранением пропорций. При закрытии страницы просмотр перестаёт
запрашивать кадры; разрешение на захват истекает через восемь секунд.


## Быстрое управление и настройки класса

При активном управлении команды проверяются без секундных пауз, кадры
в окне управления запрашиваются после завершения предыдущего запроса.
Ввод отправляется последовательно, чтобы быстрые нажатия не менялись местами.
Показатели оборудования измеряются отдельно, раз в две секунды.

В настройках ИИ рабочие места показаны сеткой. Можно отметить несколько
мест и применить ЦП, ГПУ (первую доступную на каждом ПК) или сервер.
Для конкретной видеокарты используется настройка отдельного места.
«Применено» появляется после подтверждения агента. Учебный сервер показан
отдельно; на нём выбираются только ЦП или ГПУ.

Кнопка выбора папки резервных копий открывает Проводник в приложении
на сервере. При подключении с другого ПК путь сервера или UNC вводится
вручную.

Преподаватель видит свободные места, своё место и учеников своих групп.
Доступны просмотр, управление и выход из учётных записей учеников.
Удаление устройств, закрытие приложения и настройки ИИ остаются у администратора.

На сервере: «Рабочие места» → «Учебный сервер» → карандаш → название.
Название сохраняется в базе и используется в поиске серверов. Если имя
ещё не сохранено, показывается жёлтая подсказка.


## Подсказки и выбор папки

В демонстрации страница входа уточняет роль и пароль у своего настольного
экземпляра после запуска WebView2. Поэтому подсказка появляется и у повторно
открытого второго рабочего места, даже если хранилище браузера ещё не готово
в момент первого отображения страницы. Для обычного запуска на разных ПК
демонстрационные логины не показываются.

В настройках отдельные блоки для ИИ и резервного копирования. Кнопка
«Выбрать папку» доступна в режиме демонстрации и для окна сервера, и для
окон рабочих мест; сохранённый путь должен быть доступен серверу.


## Порядок подключения и оформление

При первом запуске рабочего места на одном ПК администратор сначала выбирает
учебный сервер, затем задаёт номер этого места. Номер проверяется на выбранном
сервере. В сетевом окне настройки сервер также расположен перед полем номера.

В режиме одного ПК каждый запуск демонстрационного сервера создаёт новый
учебный профиль: имя, занятия и настройки начинаются заново. Сначала входит
администратор и задаёт название; до этого преподаватели и ученики войти
не могут. Старые демонстрационные профили остаются на диске, но новый сеанс
их не использует.

В локальной сети сервер использует сохранённую базу и имя. Администратор
задаёт название при первом запуске; после перезапуска повторная настройка
не требуется.

Панели кабинета имеют светло-серый фон; заголовки списка мест, настроек ИИ
и резервного копирования — тёмно-серые полосы. Метка роли ПК на экране входа
тёмно-серая, после входа — оранжевая. Основные кнопки синие, выбранный режим
вычисления ИИ тёмно-серый.
