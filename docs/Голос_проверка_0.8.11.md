# Голос в версии 0.8.11

## Использование

- Настройки → Генерация звука: отдельно предгенерация на сервере и живой разговор на текущем ПК.
- Для подготовки текста нового билета используется выбранная здесь Qwen3 Instruct. Авторский текст озвучивается дословно.
- В мастере на шаге проверки и в редакторе через 2,5 секунды после изменения начинают готовиться записи входящих звонков. Индикатор находится справа внизу; раскройте его для прослушивания или повторной попытки.
- Голос одного контакта сохраняется для всех его реплик. В редакторе можно выбрать мужской или женский голос. Обычные сообщения остаются текстовыми; флажок «Озвучивать сообщение» включает звук отдельно.
- Публикация сохраняет версию; запуск задания с незавершёнными обязательными записями блокируется с пояснением. Старые опубликованные билеты продолжают работать по прежним правилам.
- Подключённые разрешённые ПК каждые 30 секунд сверяют версии и SHA-256 записей. Докачка использует HTTP Range; проверенный файл переносится из временного в постоянный кэш. Получение файла не запускает воспроизведение.
- В Windows-приложении в телефоне 112: «Задать вопрос голосом», затем «Завершить вопрос». Whisper распознаёт запись, локальная Qwen формирует ответ с контекстом разговора, локальная TTS произносит его. Максимум одной записи — 15 секунд.
- Известные ответы билета имеют приоритет над генерацией. История разговора передаётся локальной модели для сохранения фактов. Ответ модели остаётся учебным материалом и может требовать предметной проверки.
- Через 1,5 секунды ожидания включается готовая короткая реплика (отключается в настройках). При завершении разговора текущие вычисления и воспроизведение отменяются.
- В браузере доступны готовые записи. Живая генерация требует Windows-приложения; на мобильных она выключена.

## Состав папки

Приложение поставляется папкой, без ZIP. Вместе с EXE сохраняйте `local_ai` и `_internal`.
`local_ai/voice/runtime` — отдельный Python 3.11 с PyTorch, Qwen-TTS, faster-whisper и зависимостями.
`local_ai/voice/models` — Silero v5, Whisper tiny/base, Qwen3-TTS 1.7B CustomVoice.
`local_ai/voice/fillers` — заранее подготовленные короткие записи ожидания.
Версии зависимостей: `local_ai/voice-requirements.lock.txt`. CPU и CUDA для речи выбираются отдельно от Vulkan для текстовой модели.

Модели используются локально. Отсутствующие веса или GPU показываются в настройках; автоматического перехода к облаку нет.

## Проверено в разработке

- 76 API-тестов: прежние сценарии, очередь, неизменность старых записей, повторное использование звука и запрет запуска без готового аудио.
- Silero CPU: запись 5,5 секунды за 1,3 секунды.
- Qwen3-TTS GPU: запись 3,44 секунды за 16,33 секунды. Whisper tiny CPU: распознавание за 0,62 секунды.
- Локальная Qwen3 0.6B правильно сопоставила перефразированный вопрос об адресе; Silero произнесла ответ за 1,08 секунды.
- Фоновая доставка настоящей записи двум отдельным клиентским профилям и чтение проверенного кэша.
- Визуально проверены настройки и индикатор готовых записей в редакторе.
- Готовый EXE прошёл встроенный self-test: настоящие Silero/Whisper, наличие четырёх звуковых моделей, WebView2, сохранение данных и остановка сервера.
- Дополнительно: Silero GPU и Whisper base GPU работают; Qwen3-TTS CPU создала 1,84 секунды речи за 38,39 секунды.

Замеры относятся к этому ПК, а не являются нормативом. Проверка физического микрофона, акустики класса и двух отдельных компьютеров требует испытания на оборудовании класса.

Источники интерфейсов моделей: [Qwen3-TTS](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice), [Silero](https://github.com/snakers4/silero-models), [faster-whisper](https://github.com/SYSTRAN/faster-whisper).
