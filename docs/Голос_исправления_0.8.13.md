# Голос и очередь — 0.8.13

- Макет чёрного телефона убран.
- В ДДС выбирается абонент, затем «Позвонить бригаде»: сообщение с микрофона распознаётся локально, ответ воспроизводится из подготовленной записи. Текстовая передача остаётся доступной.
- Озвучиваются не только входящие события, но и ответы контактов: первый ответ, последующие доклады, заданные автором ответы на вопросы.
- Три ответа вводных билетов ДДС уже включены в поставку, синтезированы Qwen3-TTS. Проверены контрольные суммы и воспроизведение WAV (4,48 / 4,40 / 3,68 секунды).
- Общая очередь видна преподавателю после публикации и переходов между вкладками. Ошибки доступны в раскрывающемся индикаторе с повторным запуском.
- При перезапуске готовые файлы используются повторно. Прерванная запись генерируется заново; остальные записи не теряются. Продолжение внутри прерванного звукового файла не поддерживается.
- Существующие билеты и незавершённые попытки получают недостающие задания озвучки при запуске.
- Исправлена передача идентификатора рабочего места при отправке диагностики. Добавлена запись ошибки React в журнал native-приложения, защищены вызовы отсутствующих голосовых методов.

## Проверки и ограничения
79 API-тестов, сборка TypeScript/Vite, ручной сценарий ДДС в браузере, фактический WAV и общий индикатор очереди. Сценарий возобновления проверен с состоянием running после перезапуска.
Первоначальная ошибка интерфейса со скриншота не воспроизведена, её точная причина не подтверждена. Живой физический микрофон в этом обновлении отдельно не проверялся.

Самопроверка собранного EXE пройдена: встроенный ответ ДДС, блокировка неготового билета, синтез/распознавание, WebView2, сохранность данных после перезапуска. Отчёт: tmp/release0813selftest-final/self-test.json.
