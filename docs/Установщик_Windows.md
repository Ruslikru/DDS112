## Для получателя

Поддерживается Windows 10/11 x64. Передайте один EXE; для работы не нужны Python, Node.js, Docker, отдельная СУБД или интернет. Программа устанавливается для текущего пользователя без запроса прав администратора. Ярлык доступен через меню «Пуск»; ярлык на рабочем столе можно выбрать в установщике.

При первом запуске задаётся пароль для учебных аккаунтов `admin`, `teacher`, `student`, `student2`. После подготовки базы открывается отдельное окно приложения со встроенным WebView2. Закрытие окна с подтверждением останавливает сервер и нейросеть. Перед выходом сохраните карточку.

Это отдельная локальная установка: у каждого получателя своя база. Сервер слушает только `127.0.0.1`, свободный порт выбирается автоматически. Для нескольких рабочих мест с общей базой используется существующее серверное развёртывание с PostgreSQL, а не эта SQLite-сборка. На macOS/Linux и Windows ARM/32-bit этот EXE не рассчитан.

Установщик не подписан сертификатом издателя. Это ограничение текущей поставки; цифровая подпись не имитируется.

## Данные и обновления

Установка программы: `%LOCALAPPDATA%\Programs\Dispetcher112`.
Данные: `%LOCALAPPDATA%\Dispetcher112`.

Перед каждым запуском сервер делает SQLite backup предыдущей базы и копирует медиа в `backups`. Это резервирование при запуске, не ежедневное расписание. Снимки автоматически не удаляются. Журналы находятся в `logs`. Пароль первого запуска не сохраняется открытым текстом; в базе используются существующие Argon2-хеши.

Обновление устанавливается поверх программы после её закрытия. Миграции базы запускаются автоматически; каталог данных не входит в установщик и не удаляется деинсталлятором. Перенос всей папки данных выполняется при остановленном сервере. Подробная памятка поставляется в `packaging/QUICKSTART.txt` и внутри приложения.

Рабочая PostgreSQL-база разработчика, `.env`, чат Telegram, исходные пользовательские документы и результаты его занятий не включаются в EXE. Включены только код, собранный интерфейс, миграции, публичная часть учебного классификатора и демонстрационные сценарии проекта.

## Сборка разработчиком

1. Windows x64, Python 3.14 с Tkinter, Node.js и виртуальное окружение `.venv`.
2. Установить серверные зависимости из `apps/api/requirements.lock.txt`.
3. Указать компилятор Inno Setup 6.7.3 (`ISCC.exe`).
4. Выполнить `powershell -File scripts/build-windows.ps1 -InnoCompiler "C:\path\ISCC.exe"`.

Скрипт устанавливает закреплённые зависимости сборщика, собирает React, собирает PyInstaller onedir, затем компилирует один установочный EXE и записывает SHA-256. Промежуточные результаты — `build/desktop-dist`, `build/desktop-work`. В `release` лежат установщик, контрольная сумма и инструкция.

Сборка основана на [PyInstaller](https://www.pyinstaller.org/en/stable/) и [Inno Setup](https://jrsoftware.org/isdl.php). Их лицензии и уведомления зависимостей включены в пакет. Наличие инструментов требуется только на машине сборки.

## Проверка

В лаунчере есть `--self-test --data-dir <новая пустая папка>`. Он поднимает именно встроенный сервер, создаёт чистую базу, проверяет вход администратора/ученика, классификатор, карточку ДДС, сохранение заметки, Tkinter, остановку, повторный запуск и резервную копию. Результат записывается в `self-test.json`; код выхода 0 означает успех. На существующую базу этот тест не запускается.

Изменение общего сервера ограничено поддержкой `APP_RESOURCE_ROOT` для поиска упакованных ресурсов; обычный запуск сохраняет прежние пути. Регрессионные интеграционные тесты приложения: 10 passed.
