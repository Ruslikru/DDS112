# Тренажёр 112 / ДДС — версия 0.8.20

## Установка на другие ПК

На этом ПК уже есть ярлык «Тренажёр 112 — последняя версия» на рабочем столе.
Он запускает `release/Dispetcher112-0.8.20-r5-portable/Dispetcher112.exe`.
Перед запуском закройте окна прежней сборки 0.8.19.

Для переноса без установки используйте один файл
`release/Dispetcher112-0.8.20-r5-portable.exe`: выберите папку распаковки,
затем откройте в ней `Dispetcher112-0.8.20-r5-portable/Dispetcher112.exe`.
Для обычной установки с ярлыком и удалением через Windows скопируйте **всю папку**
`release/Dispetcher112-0.8.20-installer`, включая EXE и все BIN, и запустите EXE.
Установщик всегда показывает выбор папки назначения.
В комплекте локальные модели Qwen3 для анализа, Qwen3-TTS, Silero v5,
Whisper tiny/base, голосовой Python и WebView2 Runtime. Отдельно ставить Python
или скачивать модели не требуется. Настройка учебного сервера и допуск рабочих
мест описаны в README.txt рядом с установщиком.

## Что добавлено

- 16 новых направлений служб: Гормост, жилищная аварийная служба, Жилищник,
  управляющая организация, Мосводосток, МОЭК, Россети Московский регион,
  Моссвет, Автомобильные дороги, Мосгортранс, Московский метрополитен,
  Мосприрода, Мосэкомониторинг, аварийная служба лифтов,
  Пожарно-спасательный центр Москвы и ОАТИ.
- В справочник также добавлены недостающие Служба 104, ЦОДД,
  Мосводоканал и МОСГАЗ. Существующие записи администратора сохраняются.
- По одному билету 112 и ДДС для каждого нового направления: **32 билета**.
  Они находятся у преподавателя в «Билеты» и доступны для назначения ученикам.
- **32 миниопроса**: 20 вопросов с выбором ответа и 12 на точность ввода.
- Готовые приветствия новых бригад для Qwen3-TTS и Silero. Пол голоса
  закреплён до начала разговора. В редакторе билета, в разделе диалога,
  можно выбрать мужской или женский голос.
- Для новых сценариев 112 сохраняется каталог из более чем 15 ответов:
  имя, телефон, адрес, обстоятельства, дети, животные, машины, цвет,
  километр, направление, доступ и другие сведения. Их можно править
  в редакторе диалога. Неизвестные сведения в старых авторских билетах
  не придумываются во время звонка.
- Мастер создания придумывает дополнительные учебные обстоятельства один раз,
  при создании, и сохраняет их в билет. Это вымышленные данные сценария,
  а не сведения о реальных происшествиях.
- В оценке разговора отделены слова ученика от ответов заявителя.
- Одна синяя кнопка «Подтвердить оценку»; после правок — «Сохранить и подтвердить».
  Подтверждение запрашивается в отдельном окне. Сохраняются решения
  преподавателя и примеры свободных ответов для того же вопроса и эталона.
  Веса модели автоматически не переобучаются; следующий результат остаётся
  предварительным до решения преподавателя.

## Службы и классификатор

У ГБУ «Гормост» подтверждены направления мостов, тоннелей, переходов и
набережных: [официальный сайт](https://gormost.mos.ru/).
В импортированном классификаторе есть виды задымления по объектам
(мусор, трава, парк, жилые объекты и т. д.), но нет отдельного столбца
ответственных служб. Каталог выше и маршруты новых билетов являются учебной
адаптацией. Принадлежность объекта и порядок взаимодействия определяет
преподаватель по регламенту своего контура. Эти билеты не заменяют регламент.

## Проверка безопасности и устойчивости

| Требование | Результат |
|---|---|
| TLS/SSL всех данных внутри контура | **Не выполнено** в штатном многопользовательском запуске. Он использует HTTP/TCP 8765. UDP 38765 служит обнаружению серверов. Установщик сам не устанавливает доверенные сертификаты. |
| RBAC | Сервер проверяет роль, владельца попытки и группу преподавателя. Проверены запреты ученику читать чужую попытку, менять её, выставлять оценки и менять голосовые настройки; запрет чужому преподавателю проверять работу и менять настройки администратора. |
| Краткий обрыв сети | 30 секунд отсутствия сети воспроизведены средствами браузера. Завершение задания сохранилось в очереди и отправилось автоматически после восстановления. Сессия сохранилась. |
| Повторная отправка | Команды имеют постоянный идентификатор. Повтор после потери ответа не должен применять действие второй раз; серверная идемпотентность проверена тестами. |
| Сохранность очереди | Действия записываются в localStorage перед отправкой, отдельно для каждой учётной записи. Перед отправкой проверяется текущий пользователь. Не очищайте данные приложения до синхронизации. |

Шифрование нельзя считать обеспеченным за счёт пароля или RBAC. Для
выполнения TLS необходима отдельная настройка доверия сертификатам и
защищённого подключения всех клиентов; в эту сборку она не входит.
Используйте вымышленные учебные данные при проверке этой версии.

При обрыве отображается «Проблемы с локальной сетью…», после восстановления —
«Подключение восстановлено…». Передаются черновики и команды завершения,
сохраняется порядок. Таймер занятия не останавливается. Звуковой разговор
не гарантирован во время отсутствия связи: запись и вопросы, которые ещё
не были переданы приложению, не входят в очередь карточек.

## Проверки

- В предыдущем проходе 106 автоматических тестов приложения прошли.
  При текущей проверке новый тест готовности звука прошёл; в файле
  `test_flows.py` остаются два старых теста с устаревшими ожиданиями:
  обязательный вызов ИИ для известного факта и скрытие вступительной реплики.
- TypeScript и Vite: успешная сборка.
- Браузер: реальная очередь при 30-секундном offline, автоматическое
  завершение попытки после восстановления без повторного входа.
- Браузер: одна синяя кнопка, окно подтверждения поверх результата,
  отказ от подтверждения, изменение критерия и успешное сохранение.
- Реальная предгенерация новых приветствий Qwen3-TTS и Silero;
  голоса Ryan / ru_eduard закреплены за репликами бригад.
- Новый билет не выбирается и не запускается, пока не готовы все его записи;
  виден прогресс генерации. Проверены блокировка, автоматическое появление
  доступности и серверный запрет при прямом запросе.

Не проверены физическое отключение сетевого кабеля/Wi-Fi и работа
на чужом ПК. Это нужно проверить установленной сборкой в вашем классе.

Проверена настоящая установка предыдущего EXE в отдельную папку. Самопроверка
последней переносной версии завершилась успешно: WebView2, TTS/STT, права на голосовые
настройки, сохранение базы при перезапуске и резервная копия. Отчёт
`SELF-TEST.json` приложен к установщику. Тестовая установка после проверки удалена.
Проверка реального микрофона не выполнялась: STT тестировался на синтезированном WAV.
