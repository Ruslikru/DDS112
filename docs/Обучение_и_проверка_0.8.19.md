# Обучение и проверка работ — 0.8.19

## Что изменено

- Подсказки 112 следуют заполнению карточки. Нажимать готовые вопросы не требуется: сведения можно уточнять через микрофон. Шаги перенумерованы.
- Реплики активной попытки проверяются фоновым обработчиком. Результат хранится в базе и используется при завершении. Новые реплики делают прежний разбор неактуальным. После окончания разговора 112 / реагирования ДДС заранее готовится итоговый отчёт, если все критерии уже оценены. Изменение карточки требует обновления отчёта. Если модель занята, задача ожидает освобождения.
- Пока отчёт не готов, показываются широкая полоса ожидания, текущий этап и время ожидания. Открытие окна результата не запускает проверку: её запускает серверный обработчик.
- «Журнал» преподавателя использует тот же список происшествий, что у ученика. В нём реальные карточки, а не ещё не начатые назначения. Закрытие карточки и ссылка возврата ведут в журнал.
- Отдельная вкладка «Проверка работ»: фильтр по ученику и состоянию, просмотр карточки и разговоров, изменение критериев либо «Подтвердить текущую оценку». Подтверждение сохраняет частичные баллы ИИ.
- Минизадания открываются по центру с затемнением фона; фокус клавиатуры остаётся в окне.
- ДДС: нажмите карандаш своей службы → «Добавить комментарий · статус не меняется» → введите комментарий → галочка. Запись добавляется в историю с текущим статусом и временем, без ложного перехода в «Прибытие». Завершённую работу службы редактировать нельзя. Основание: предоставленное руководство «Работа с АРМ-112 для ДДС от ОКр_ГСИ», страницы 21–23: ход реагирования, комментарии и прекращение редактирования после завершения.
- Аналитика обновляется каждые 3 секунды. Средний балл и сортировка учитывают проверенные вводные работы. Освоенная сложность и карта ошибок самостоятельных работ сохраняют отдельный смысл; пояснение показано на странице.

## Проверки

- 103 теста API прошли. Новые проверки: разбор активного разговора; инвалидирование после новых реплик; переиспользование итогового отчёта; подтверждение без потери частичного балла; комментарий ДДС без смены статуса; запрет комментария после завершения.
- После добавления примеров преподавателя в ранний анализ повторно прошли 4 затронутых теста.
- TypeScript и production-сборка прошли. Vite предупреждает о размере общего JS-файла; ошибок сборки нет.
- В браузере проверены журнал и возврат из карточки, подтверждение результата, продвижение подсказки по заполнению поля, запись комментария и закрытие окна. Для визуальной проверки состояния загрузки и минизадания использованы контролируемые ответы API только в браузере.
- Сценарий физического микрофона и измерение ускорения на реальном Qwen в этой версии не выполнялись. Фоновое переиспользование проверено с управляемым ответом модели, а не по качеству её оценки.

## Запуск

Закройте предыдущую версию. Запускайте `Dispetcher112.exe` из папки `release/Dispetcher112-0.8.19-training`, сохраняя рядом `_internal` и `local_ai`.

Готовый EXE прошёл встроенный тест: ok=true, frozen=true, WebView2 и голосовой мост готовы, синтез и распознавание доступны, данные переживают перезапуск, тестовый сервер остановлен. Отчёт: tmp/selftest019/self-test.json. Это техническая проверка голосового тракта на тестовой записи, а не оценка точности распознавания речи человека.
