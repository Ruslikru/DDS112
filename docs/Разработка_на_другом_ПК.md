# Продолжение разработки на другом ПК

Репозиторий хранит исходный код приложения, миграции, начальные билеты, справочник, скрипты сборки и документацию. Локальные базы, загруженные медиа, журналы, результаты тестовых запусков, установщик, зависимости и веса модели в Git не входят.

## Получить и запустить исходники на Windows

1. Установить Git, Python 3.13+ и Node.js 24. Docker Desktop нужен только для PostgreSQL; для локальной разработки можно использовать SQLite.
2. Клонировать репозиторий и открыть папку проекта в терминале.
3. Выполнить команды:

```powershell
Copy-Item .env.example .env
npm ci
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r apps/api/requirements.lock.txt
npm run build
./scripts/start-local.ps1
```

В `.env.example` выбран SQLite. При первом запуске приложение создаст новую базу и демоданные. Замените `replace-with-demo-login-password` в `.env` на собственный пароль до запуска. Адрес приложения: `http://localhost:8000`. Для разработки интерфейса во втором терминале выполните `npm run dev`.

Если нужны накопленные попытки и пользовательские билеты с прежнего ПК, перенесите их отдельно: SQLite-файл и `var/media` либо резервную копию PostgreSQL вместе с медиа. Эти данные намеренно не публикуются в Git. Инструкция по резервированию есть в [README](../README.md#резервное-копирование).

## Локальная ИИ-модель

Код интеграции модели входит в репозиторий. Веса GGUF (около 2,5 ГБ) и исполняемые файлы llama.cpp исключены из Git из-за размера. Для работы функций ИИ на новом ПК скачайте модель и CPU-сборку llama.cpp, разместите их по путям из [local_ai/README.md](../local_ai/README.md) и [manifest.json](../local_ai/manifest.json), затем сверьте SHA-256 модели с манифестом. Без них основные сценарии тренажёра и редактирование билетов доступны, а функции локальной ИИ — нет.

Для сборки установщика также нужны Inno Setup и зависимости из [инструкции](Установщик_Windows.md); готовый EXE в Git не хранится.
