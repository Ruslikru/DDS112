# АРМ-112: сверка интерфейса и голосовой связи, 0.8.14

## Что изменено

- Журнал: тёмный расширенный поиск, видимая кнопка сброса, пустой список без надписей, удалены переключатели ДДС/112.
- Панель оператора: номер учётной записи, ФИО, номер подключённого рабочего места, настройки, помощь и выход. Настройки и помощь объясняют ограничения учебной версии.
- Восстановлен ряд вкладок. Журнал и ВИКИ работают; остальные приглушены и недоступны.
- «Выберите что показать» фильтрует свои карточки: в работе, завершённые, закреплённые. Уведомления показывают ожидающие звонки по доступным карточкам.
- «Выберите группу» присутствует как неактивный элемент. Его точное назначение в показанной версии не установлено; он не подменён выбором учебной группы.
- Предпросмотр журнала показывает время последних статусов служб; описание видно и в свёрнутой строке. Номер оператора сохраняется для новых карточек 112, номер АРМ берётся из подключённого рабочего места. Неизвестные данные автора полученной карточки не выдумываются.
- Удалена печать карточки. Добавлены неактивные значки сообщений под телефонными трубками. Кнопки «нет контакта» и «срыв звонка» остаются в отдельном блоке.
- Учебная категория больше не подставляется в поле класса происшествия. Пустая опросная карта не содержит технического пояснения про отсутствие признаков в билете.
- Телефон закреплён внизу правой панели. Быстрые контакты, зелёная трубка для вызова/приёма и красная для окончания. История и настройки открываются над телефоном; подсказки прокручиваются отдельно.
- Текстовый чат включается в настройках голоса на конкретном ПК. По умолчанию основное управление голосовое.
- «Мои билеты»: назначенные билеты и вводные упражнения. «Занятия с преподавателем»: учебные сеансы. «Мой прогресс»: результаты вошедшего ученика, ограниченные серверной проверкой доступа. Материалы и горячие клавиши доступны через ВИКИ.
- В новых попытках вместо общего номера +7 (000) 000-00-01 используются разные синтетические номера. Внешней телефонии нет; совпадение учебного номера с реальным абонентом ничего не вызывает.

## Голос и совместимость

В момент проверки были запущены EXE из папок 0.8.0 и 0.8.13. В классе интерфейс приходит с сервера, а распознавание/синтез выполняет приложение на конкретном ПК. Поэтому новый интерфейс может встретить старый нативный модуль.

- Перед записью проверяется готовность голосовых функций.
- Если старый голосовой модуль не имеет `allow_microphone`, используется штатное разрешение WebView; вызова отсутствующей функции больше нет.
- Если отсутствует сам голосовой модуль, показывается понятное сообщение о необходимости актуальной сборки на этом ПК.
- Голосовой ответ 112 запускается независимо от раскрытия телефонного окна; есть индикация подготовки и повторное прослушивание.
- Ответы бригад проигрываются из готовых аудиозаписей. Проверена загрузка и проигрывание ответа «Заявку приняли…» длительностью 4,48 с.
- Нативный голосовой интерфейс выделен в общий класс для рабочего окна и проверки EXE.
- Сохранённый путь автообновления учитывается только для более новой версии; новый EXE не перенаправляется на старый.

Для проверки класса нужно запускать одну актуальную сборку на сервере и учениках. Старые папки и базы сохранены.

## Что означают вкладки оригинала

Памятка ГБУ «Система 112» 2025 года, стр. 11, прямо указывает: пример главного экрана показан для роли **контролёра**; набор вкладок зависит от прав. Это не полный набор обязательных функций ДДС.

| Элемент | Что установлено |
|---|---|
| Журнал | Список полученных карточек, поиск и предпросмотр. Подтверждено памяткой. |
| ВИКИ | В тренажёре справка, горячие клавиши и материалы преподавателя. Полное содержание оригинальной ВИКИ не предоставлено. |
| Контроль | Памятка описывает контроль реагирования служб отдельным подразделением. Точный состав экрана этой вкладки не показан. |
| БДПН | Общепринятое значение — база данных перенесённых абонентских номеров. Материалы МСЭ подтверждают взаимодействие БДПН с системой 112; точные функции этой кнопки не установлены. |
| УЕР | Надёжная расшифровка именно для показанной программы не найдена. |
| Экран | Назначение не описано; возможно, дополнительное представление оперативной обстановки. Это предположение. |
| Статистика / Отчёты | По названию — показатели работы и отчётность. Состав данных оригинала не подтверждён; это не учебная статистика студента. |
| Заявители | По названию — сведения о заявителях. Возможности оригинального раздела не подтверждены. |
| Техника | По названию — сведения о технике/средствах служб; не подтверждено. |
| Аудит | По названию — история действий; состав и права не подтверждены. |
| Смена | По названию — управление сменой; конкретные действия не подтверждены. |
| Регионы | По названию — региональные данные или взаимодействие; не подтверждено. |
| Значок сообщения у телефона | Вероятно, сообщения по номеру. В руководствах других АРМ есть SMS, но привязка к этой конкретной иконке не подтверждена. В тренажёре значок неактивен. |

## Источники и горячие клавиши

Основной визуальный источник: предоставленная пользователем памятка «Работа на АРМ-112», отдел контроля реагирования Службы 112, ГБУ «Система 112», 2025, страницы 11–18, 35–40. Карточка ДДС после сохранения отличается от формы ввода оператора 112; это различие сохранено.

В интернете найдены руководства **другого интерфейса**, поэтому их комбинации не объявлены горячими клавишами московского ПОВ-112:

- [Искра Технологии: руководство пользователя С-112](https://www.iskratechno.ru/upload/iblock/6c4/u27iwtbdlxy4y4hp6ap75rxr5h097huw/Руководство%20пользователя%20С-112.pdf), раздел 1.4: Enter принимает вызов, Ctrl+Enter сохраняет изменения и возвращает к списку, Esc возвращает к списку карточек. SMS описаны отдельно.
- [МСЭ: материалы семинара о переносимости номеров и взаимодействии с системой 112](https://www.itu.int/ru/ITU-D/Regional-Presence/CIS/Pages/EVENTS/2018/03_Moscow/03_Moscow_Presentations.aspx).

В ВИКИ тренажёра перечислены реально работающие сочетания: Ctrl+Enter — принять входящий вызов 112, Alt — управление обучением, Tab/Shift+Tab — перемещение по полям. Они не выдаются за точное повторение оригинала.

В ВИКИ также полезны памятка по статусам ДДС, примеры комментариев, порядок уточнения адреса и границы ответственности служб. Преподаватель уже может добавлять такие материалы для группы.

## Проверки

- TypeScript и production-сборка Vite.
- 79 API-тестов: вводные билеты, доступ к своим данным, состояния попыток, готовые ответы бригад, очередь генерации и восстановление.
- Визуальная проверка журнала, карточек 112/ДДС и телефона при 1600×950 и 1366×768.
- Сценарий ДДС с тестовым микрофонным потоком и старым мостом без `allow_microphone`: передача сообщения, получение настоящего готового WAV, успешное воспроизведение.
- Отдельная проверка EXE использует реальный WebView и голосовой движок: разрешение через JS, синтез и распознавание синтезированной фразы. Результат сохраняется в `self-test.json`.
- Итоговая проверка EXE успешна: `tmp/release0814selftest-final/self-test.json`, `ok: true`, `native_voice_bridge.allowed: true`, `audio: true`. Сохранение данных и резервная копия после перезапуска подтверждены.
- Проверены поиск/сброс/фильтры журнала, переход в ВИКИ, отсутствие фильтра чужих учеников в личной статистике, включение чата в настройках. В финальном браузерном сценарии ошибок консоли нет.
- Акустическая цепочка «голос человека → физический микрофон → динамики» и работа на другом физическом ПК остаются для проверки на месте. Синтетический поток не заменяет эту проверку.
