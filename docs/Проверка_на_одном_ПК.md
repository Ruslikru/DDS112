# Проверка тренажёра на одном ПК

**Для работы с билетами достаточно одного окна программы.** Сервер и ученик могут работать на одном компьютере по очереди. Второй компьютер и браузер не нужны.

Если в версии 0.7.1 окно «ПК 1 · Не вошёл» закрыло весь интерфейс, завершите старую программу сочетанием **Alt + F4** и запустите версию 0.7.2. Сохранённая учебная база останется на месте.

1. Запустите `release/Dispetcher112-0.7.2/Dispetcher112.exe`. Если программа уже использовалась и вы хотите отдельную проверочную базу, откройте PowerShell **в папке проекта** и запустите:

   ```powershell
   $exe = (Resolve-Path '.\release\Dispetcher112-0.7.2\Dispetcher112.exe').Path
   $testData = Join-Path $env:LOCALAPPDATA 'Dispetcher112-OnePcTest'
   Start-Process -FilePath $exe -ArgumentList ('--data-dir "' + $testData + '"')
   ```

   При повторной проверке используйте ту же команду. Папка `Dispetcher112-OnePcTest` отделена от обычных данных тренажёра. Если уже запущена другая копия учебного сервера, закройте её перед запуском: сервер использует порт 8765.

2. При первом запуске выберите **«Учебный сервер»**, номер ПК **1**, задайте пароль и нажмите **«Запустить учебный сервер»**. Войдите как **`admin`** с этим паролем.
3. В разделе **«Рабочие места»** нажмите **«Допустить ПК»** для ПК 1, если он ожидает допуска.
4. В правом верхнем меню нажмите **«Выход»**. В том же окне войдите как **`student`** с паролем, который задали при создании проверочной базы.
5. Пройдите вводное знакомство с интерфейсом. На шагах с горячими клавишами нажмите **Ctrl + Enter** и **Alt**.
6. Откройте **«Задания»** и выберите начальный билет **«Задымление мусоропровода»**. Начните карточку, заполните её, завершите и посмотрите результат. Модель Qwen3 0,6B проверяет свободный текст локально на процессоре этого ПК. Для просмотра как преподаватель выйдите из учётной записи ученика и снова войдите как `admin` или `teacher`.

Путь выше проверен с одним допущенным рабочим местом: после выхода администратора ученик вошёл на том же ПК и открыл начальный билет.

## Если нужны два окна одновременно

Для просмотра экрана ученика и показа преподавателя нужны **две сессии**, но они тоже могут работать на одном ПК. Оставьте администратора в приложении. Откройте в Microsoft Edge [http://127.0.0.1:8765](http://127.0.0.1:8765), укажите номер ПК **2**, допустите его в окне администратора, затем войдите в Edge как `student`. Внизу окна ученика нажмите «Показать мой экран преподавателю». Миниатюра появится у администратора.

Для проверки **выбора сервера из списка** можно открыть вторую копию EXE с отдельной папкой данных:

```powershell
$clientData = Join-Path $env:LOCALAPPDATA 'Dispetcher112-OnePcClientTest'
Start-Process -FilePath $exe -ArgumentList ('--data-dir "' + $clientData + '"')
```

Выберите «Рабочее место», номер **3** и работающий сервер из списка. Администратор допустит ПК 3. Для обнаружения используется UDP 38765, для работы приложения — TCP 8765.
