# Учебные серверы и вычисления — 0.8.0

Каждый запуск EXE сначала предлагает два варианта: демонстрация на одном ПК или
работа нескольких ПК в локальной сети. При демонстрации первый экземпляр
становится сервером, следующие — рабочими местами. Новый демонстрационный
сервер создаёт учётные записи `admin`, `teacher`, `student`, `student2` с паролем
`12345678`; существующая демобаза сохраняет ранее заданный пароль. Допуск
демонстрационных рабочих мест выполняется автоматически.

При выборе локальной сети открывается окно выбора роли ПК. Сохранённые значения уже выбраны.
Учебный сервер хранит базу своего класса; рабочее место подключается к выбранному
серверу из списка. При отсутствии серверов можно создать свой. Название сервера
задаётся при настройке, рядом в списке виден его адрес. Два сервера на разных ПК
одной сети обслуживают независимые классы и отдельные учётные записи.

Роль ПК не ограничивает роль вошедшего пользователя: администратор, преподаватель
и ученик могут использовать любой ПК. Ученику нужен допуск рабочего места.
Телефон подключается браузером по адресу из панели «Подключить ПК или телефон».
Автоматическое обнаружение UDP работает в Windows-приложении; браузер телефона
использует выбранный адрес сервера. Все устройства должны иметь связь внутри LAN.

## Вычисления ИИ

Администратор в «Состоянии системы» выбирает сервер или выбранные ПК класса.
Сервер использует CPU либо GPU через Vulkan. На вычисляющих ПК запускается
встроенная CPU-модель; каждый ПК обрабатывает одну задачу одновременно.
Разрешение на вычисления выдаётся отдельно от допуска рабочего места.
Разрешённым ПК передаются данные запросов, включая эталоны предварительной оценки.

Клиенты опрашивают только выбранный сервер с токеном своего рабочего места.
Браузер телефона вычислительным узлом не является. Когда нет свободного узла,
ответ узла ошибочен или истёк срок ожидания, используется модель сервера.
Узлу нельзя забрать чужую задачу или сдать результат за другой узел.
Результат модели проверяется по форме ожидаемого ответа; итоговая оценка
по-прежнему требует утверждения преподавателя.

## Поставка

`release/Dispetcher112-0.8.0/Dispetcher112.exe` запускается вместе с соседними
папками `_internal` и `local_ai`. Включены Qwen3 0.6B, CPU и Vulkan runtime.
Для переноса используйте всю папку либо архив `Dispetcher112-0.8.0-win-x64.zip`.
Пользовательские базы в архив не входят. Для работы нужен WebView2 Runtime.

Физическая сеть с несколькими серверами, телефоны и большой учебный класс требуют
проверки на целевом оборудовании. Работоспособность GPU зависит от драйвера Vulkan.
