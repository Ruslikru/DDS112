# Тренажёр 112 / ДДС

Учебное приложение для операторов 112 и диспетчеров ДДС. В этом репозитории — исходный код; готовая сборка и модели находятся отдельно.

## Запустить готовую версию на Windows

Скачайте прототип по ссылке выше. Если это переносная версия одним EXE, запустите файл, выберите папку распаковки, затем откройте `Dispetcher112.exe` в распакованной папке. Если скачан установщик, запустите `Dispetcher112-Setup-*.exe` вместе с файлами BIN из того же комплекта.

При первом запуске для проверки на одном компьютере выберите **«Запустить на одном ПК»**. Вход — по данным ниже. Python и Node.js для готовой версии не нужны.

| Учётная запись | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `12345678` |
| Преподаватель | `teacher` | `12345678` |
| Ученики | `student1` — `student5` | `12345678` |

Это демонстрационные учётные записи для режима одного ПК.

## Запустить из исходного кода

Понадобятся Python 3.13+ и Node.js 24+. В PowerShell:

```powershell
git clone https://github.com/Ruslikru/DDS112.git
cd DDS112
.\scripts\start-local.ps1
```

После запуска откройте [http://localhost:8000](http://localhost:8000). Для новой локальной базы доступны `admin`, `teacher`, `student` и `student2` с начальным паролем `Training112!`. При необходимости пароль первого запуска задаётся переменной `DEMO_PASSWORD`. Веса голосовых моделей в Git не входят.
